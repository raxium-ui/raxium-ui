# PinInput

`PinInput` 用于验证码、OTP、PIN 等按格输入场景。组件基于 Ark UI Pin Input 构建，通过 `count` 在内部渲染格子，无需 `v-for`；`separator` 可在格子之间插入分隔符。支持受控/非受控值，并扩展 `theme` 与 `ui` 样式入口。
