# Editable

`Editable` 把静态文本切成就地编辑，适合昵称、标题、备注。React 入口是复合组件：`Editable`、`Editable.Input`、`Editable.Preview`（亦可具名导入）。基于 Ark Editable **`Root`**。根扩展 `theme` / `craft` / `className` / `ui`；`Input` 扩展 `clearable`。编辑态用 `useEditableContext()`，不要做成 Vue 作用域插槽。

## ARK UI Link

- 根透传 `value` / `onValueChange` / `edit` / `onEditChange` 等，并增加 `theme` / `craft` / `ui` / `prefix` / `suffix`。
- `Input` / `Preview` 对应 Ark 子原语；`Input` 额外提供清空。
- `Control` / `EditTrigger` / `SubmitTrigger` / `CancelTrigger` 复用 Ark 导出。

文档：[Ark UI Editable (React)](https://ark-ui.com/react/docs/components/editable)

### Editable.Input

`clearable`：`true` 显示默认图标；传入 `ReactNode` 替换图标。编辑态且非空时显示。

### Editable.Preview

预览区，可透传 Ark Preview 属性。

## 最佳实践

- 保持 `Editable` + `Input` + `Preview`。
- 需要提交/取消按钮时用 `activationMode="none"` + `Control` / Trigger，编辑态用 context hook。
- 清空配置在 `Input.clearable` 上。
- 持久化优先听 `onValueCommit`，不要只靠 `onValueChange`。
