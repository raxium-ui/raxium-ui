## API

`variant`：`pulse | wave`（默认 pulse）。`shape`：`rect | circle`（默认 rect）。`theme`：`ThemeProps`。`craft`：`CraftOverride<'tvSkeleton'>`。`className` 用于尺寸。

`skin`：`default | razer | shadcn`。`surface`：`light | dark | system`。
