# Pagination

页码导航。React 复合组件：`Pagination`、`GoTo`、`GoToTrigger`、`PageSize`；根内建 `Prev` / `Next` / `Item` / `Ellipsis` / 首末页（与 Vue 能力对齐）。根用 Ark **`Root`**。受控：`page` / `onPageChange`，`pageSize` / `onPageSizeChange`。`GoTo` 组合 `NumberInput`，`PageSize` 组合 `Select`。

## API

### Pagination

`page` / `defaultPage`。`pageSize` / `defaultPageSize`。`count`。`siblingCount`。`dynamicPageEnd`。`theme`：`ThemeProps`。`craft`：`CraftOverride<'tvPagination'>`。

### Pagination.GoTo / GoToTrigger

跳转页。`NumberInput` 经 `widget.input` 透传。`GoToTrigger` 提交当前输入。

### Pagination.PageSize

`sizes` 默认 `[10, 20, 30, 50]`。组合已有 `Select`。
