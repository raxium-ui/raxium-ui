# Button

`Button` 用于触发操作、提交表单或快捷动作。基于 Ark `ark.button`，由 **`tvButton`** 提供 **variant** 与 **color**、尺寸与加载态，并支持 ripple、`theme` / `craft`、`ui`。

## ARK UI Link

底层是原生 `<button>`。透传 `type`、`disabled`、`aria-*`、`data-*` 等；`variant`、`color`、`ripple`、`loading`、`theme` / `craft`、`ui` 为 Raxium 扩展。

- 文档：[Ark UI React Factory](https://ark-ui.com/docs/guides/composition)

## 最佳实践

- 用 **variant + color** 表达形态与语义，少写死颜色 class。
- 图标按钮用 **`variant="icon"`**，并给 `aria-label`。
- 异步用 **`loading`**（必要时再加 `disabled`），避免连点。
- 尺寸走 **`theme.size`**；局部用 `ui` / `className`；改 `tvButton` 结构再用 `craft` 或 `RUIConfig preset`。
- **`ripple`** 适合强调反馈；密集表单里慎用。
- 自定义加载内容用 **`loadingIndicator`**，不要做成 `loadingSlot`。
