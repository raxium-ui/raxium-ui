# HoverCard

`HoverCard` 是可交互的悬停浮层。React 入口是复合组件：`HoverCard`、`Trigger`、`Content`、`Arrow`。根用 Ark **`Root`**，并从 `RUIConfig.hoverCard` 合并 `openDelay` / `closeDelay` / `lazyMount` / `unmountOnExit` / `placement` / `theme`。

`Content` 会把 `HoverCard.Arrow` 抽到内层包裹之外，其余 `children` 放进 `contentInner`。不要用 Vue 的 `HoverCardContext` 插槽；需要 API 时用 `useHoverCardContext()`。

## ARK UI Link

- 根透传 Root（`open` / `defaultOpen`、`positioning`、delay、presence）。
- `Trigger` 复用 Ark 导出。
- `Content` 包 Positioner + Content + inner，并用 teleport depth 管理 z-index。
- `Arrow` 由内部 `createArrow` 包 Ark Arrow / ArrowTip。

文档：[Ark UI Hover Card (React)](https://ark-ui.com/react/docs/components/hover-card)

### HoverCard.Content

`className` 盖在 content 槽；`ui.positioner` / `ui.content` / `ui.inner` 分槽覆盖。`children` 里的 `HoverCard.Arrow` 会提到 inner 外。

### HoverCard.Arrow

`theme` 为 `ThemeNoCrafts`；`ui.arrow` / `ui.arrowTip`。

## Theme Configuration

根 **`tvHoverCard`**。`size`：`xs | sm | base | lg`；`skin`：`default | razer | shadcn`；`surface`：`light | dark | system`；`bordered` 默认 `true`。

## 最佳实践

- 用 `Trigger asChild` + `Content`（内含 `Arrow`）的标准结构。
- 受控用 `open` + `onOpenChange`。
- 列表里建议加大 delay，减少误触。
- 重交互改用 Dialog，不要把复杂流程放进悬停层。
