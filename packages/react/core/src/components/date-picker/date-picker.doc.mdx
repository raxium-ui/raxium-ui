# DatePicker

`DatePicker` 用于单日期与日期范围选择，支持日/月/年多视图、受控状态、禁用日期与事件监听。React 入口是复合组件：`DatePicker`、`DatePicker.Control`、`DatePicker.Content`、`DatePicker.DayView` / `MonthView` / `YearView`（亦可具名导入）。基于 Ark Date Picker **`Root`**（不是 `RootProvider`）。根扩展 `theme` / `craft` / `className`；弹层可用 `prefix` / `suffix`（`ReactNode`）。适用于表单录入、筛选面板与时间范围查询。

## ARK UI Link

- 根透传 Ark `DatePickerRootBaseProps`（`value` / `onValueChange` / `open` / `view` 等），并增加 Raxium **`theme` / `craft`**（作用于 **`tvDatePicker`**）。
- `Control` / `Content` / `*View` 在 Ark 原语外增加了默认结构与 `tvDatePicker` / `tvDatePickerView` 样式。
- 触发器、展示文案复用 Ark `DatePicker.Trigger` / `DatePicker.ValueText`。
- 日历状态用 `useDatePickerContext()`，不要做成 Vue 作用域插槽。

文档：[Ark UI Date Picker (React)](https://ark-ui.com/react/docs/components/date-picker)

## 最佳实践

- 保持 `DatePicker` + `Control` + `Content` + `*View` 组合，避免跳过控制区。
- 表单优先受控 `value` / `onValueChange`；需要外部驱动弹层时再受控 `open`。
- 范围选择显式 `selectionMode="range"`，并用 `DatePicker.ValueText` 展示区间。
- 禁用日期统一走 `isDateUnavailable`。
- 视图切换按钮是否出现，取决于 Content 里实际挂了哪些 View（通过 `displayName` 识别）。
