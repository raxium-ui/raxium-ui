# Icon

`Icon` 基于 Iconify，用于在按钮、表单、列表和状态里统一渲染图标。不是 Ark 业务组件。叶子组件：`theme` / `craft`（`tvIcon`）与 `className`。尺寸跟行高走（默认 `size-[1lh]`），**不提供 `theme.size`**。

额外 Iconify 参数（`ssr`、`rotate`、`flip`、`inline` 等）按 React `className` 习惯透传到 `@iconify/react`。

## Theme Configuration

`tvIcon` 默认 `size-[1lh]`。`skin`：`default | razer | shadcn`；`surface`：`light | dark | system`。无 `theme.size`。

## 最佳实践

- 统一 Iconify 命名空间（如 `lucide:*`）。
- 与文字对齐时改父级字号，不要给 Icon 单独设 `theme.size`。
- 点击/可访问性由外层 `button` / `a` 承担，不要给 Icon 绑交互。
