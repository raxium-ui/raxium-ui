# Collapsible

`Collapsible` 在有限空间里展开/收起内容。React 入口是复合组件：`Collapsible`、`Collapsible.Trigger`、`Collapsible.Content`（亦可具名导入）。长文本场景用独立的 `ReadMore`。基于 Ark Collapsible **`Root`**（不是 `RootProvider`）。根上扩展 `theme` / `craft` / `className`，触发器扩展 `indicator` 与 `ui`。

## ARK UI Link

- 根透传 `open` / `defaultOpen` / `disabled` / `collapsedHeight` / `onOpenChange` 等，并增加 `theme` / `craft` / `className`。
- `Trigger` / `Content` 对应 Ark 子原语。
- `ReadMore` 是业务封装，不是 Ark 一对一子组件。
- 展开态用 `useCollapsibleContext()`，不要做成 Vue 作用域插槽。

文档：[Ark UI Collapsible (React)](https://ark-ui.com/react/docs/components/collapsible)

## 最佳实践

- 结构：`Collapsible > Trigger + Content`。
- 受控用 `open` + `onOpenChange`。
- 自定义图标：`indicator=&#123;&lt;Mark /&gt;&#125;`，在组件里调 `useCollapsibleContext()`。
- 长文本用 `ReadMore` + `collapsedHeight`，不要自己量高度。
- 节奏用 `theme.size`，局部用 `ui` / `className`，改结构再用 `craft` 或 `RUIConfig preset`。
