# Hotkey

`Hotkey` 用于采集和展示快捷键组合（如 `Ctrl + Shift + K`）。基于 Ark factory（`ark.div` / `ark.input`），不是 Ark 独立业务组件。扩展热键解析、删除清空、IME 保护，以及 `theme` / `craft` / `ui`。

React 用 `hotkey` + `onHotkeyChange` 代替 Vue 的 `v-model:hotkey`。

## 最佳实践

- 用 `hotkey` + `onHotkeyChange` 作为单一事实源。
- 持久化听 `onChange`，清空听 `onCancel`。
- 中文输入法场景听 `onError` 并提示关闭 IME。
- 可查看不可改用 `readOnly`，不可交互用 `disabled`。
