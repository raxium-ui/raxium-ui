# Input

`Input` 用于单行文本输入。叶子组件：原生 `<input>` 外包一层容器，并提供 `clearable`、`prefix` / `suffix`、`theme` / `craft` / `ui`。

React 用 `value` + `onValueChange` 代替 Vue 的 `v-model`。Vue `#prefix` / `#suffix` 对应 `prefix` / `suffix` ReactNode。`readOnly` 对应 Vue `readonly`；`maxLength` / `minLength` 对应 `maxlength` / `minlength`。

## ARK UI Link

不是 Ark 业务组件。容器与输入框用 factory（`ark.div` / `ark.input`）。其余 `autoComplete`、`name`、`aria-*` 等透传到内部 input。

## 最佳实践

- 外部管值用 `value` + `onValueChange`，只初始化用 `defaultValue`。清空时 `onValueChange` / `onClear` 收到 `''`。
- `placeholder` 不能替代 label，配合 label 或 `aria-label`。
- 可看不可改用 `readOnly`，不可交互用 `disabled`。
- 尺寸走 `theme.size`，不要用 `ui.input` 去改 height。
