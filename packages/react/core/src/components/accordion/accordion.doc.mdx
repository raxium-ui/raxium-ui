# Accordion

`Accordion` 将内容分成可独立展开/收起的区块，适合 FAQ、设置分组、长表单分节。React 入口是复合组件：`Accordion`、`Accordion.Item`、`Accordion.Trigger`、`Accordion.Content`（也可具名导入 `AccordionItem` / `AccordionTrigger` / `AccordionContent`）。基于 Ark UI Accordion 的 **`Root`**（不是 `RootProvider`）。根上扩展 `theme` / `craft` / `className`，触发器扩展 `indicator` 与 `ui`。

## ARK UI Link

透传边界以 `props.ts` 中接口继承为准（`AccordionRootBaseProps`、`AccordionItemBaseProps` 等）：

- 根继承 Ark `Root` 能力（`value` / `defaultValue`、`multiple`、`collapsible`、`disabled`、`orientation`、`onValueChange` 等），并增加 `theme`、`craft`、`className`。
- `Accordion.Item` / `Trigger` / `Content` 对应 Ark 的 Item、ItemTrigger、ItemContent。
- 面板展开态用 `useAccordionItemContext()`（在 Item 子树内），不要做成 Vue 式 scope slot。

Ark UI 文档：[Ark UI Accordion (React)](https://ark-ui.com/react/docs/components/accordion)

## 最佳实践

- **结构**：`Accordion > Accordion.Item > Trigger + Content`；每个 Item 要有稳定唯一的 `value`。
- **单选全关**：根上设 `collapsible`；多选用 `multiple` + `defaultValue` / `value`。
- **受控**：`value` + `onValueChange`；不要同时传 `value` 与 `defaultValue`。
- **禁用**：整组用根 `disabled`；单节用 `Accordion.Item disabled`。
- **展开态**：在 Item 子树里调 `useAccordionItemContext()`，不要给 Trigger 做 render-prop / slot。
- **样式**：节奏用根 `theme.size`；局部用 `ui` / `className`；改 `tv*` 结构再用根 `craft` 或应用 `RUIConfig preset`。
