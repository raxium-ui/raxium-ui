# Checkbox

`Checkbox` 用于布尔选择与多选集合。支持勾选、混合态（`indeterminate`）和组内多选。基于 Ark Checkbox **`Root`** / **`Group`**（不是 `RootProvider`）。根上扩展 `theme` / `craft` / `ui` / `label` / `indicator`。

## ARK UI Link

`CheckboxProps` 继承 Ark `CheckboxRootBaseProps`。组值由 `Checkbox.Group`（亦可具名 `CheckboxGroup`）管理。

- 文档：[Ark UI Checkbox (React)](https://ark-ui.com/react/docs/components/checkbox)
- 展开态用 `useCheckboxContext()`，不要做成 Vue `#indicator` 作用域插槽。

## 最佳实践

- 单项用 `checked` + `onCheckedChange`；中间态用 `'indeterminate'`。
- 多选用 `Checkbox.Group` 的 `value` / `onValueChange`，不要自己拼数组。
- 表单设 `name` / `value` / `required`。
- 自定义勾选图标：`indicator=&#123;&lt;Mark /&gt;&#125;`，在 `Mark` 里调 `useCheckboxContext()`。
- 禁用/只读/错误用语义 props，不要只用 class 灰化。
