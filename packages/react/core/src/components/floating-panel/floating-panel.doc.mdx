# FloatingPanel

`FloatingPanel` 是可拖拽、可缩放、可分阶段（最小化/最大化/默认）的浮动面板。React 入口是复合组件：`FloatingPanel`、`Trigger`、`Content`、`Header` 以及各类 Trigger。基于 Ark Floating Panel **`Root`**。根扩展 `theme` / `craft`、`opacity`、`pinned`、`resizeAxis`。透明度与固定状态用 `useFloatingPanelAppearance()`，不要做成 Vue 作用域插槽。

## ARK UI Link

- 根透传 Ark Root 状态（open、size、position、拖拽等），并增加 `theme` / `craft` / `opacity` / `pinned` / `resizeAxis`。
- `Trigger` 复用 Ark 导出。
- `Content` Portal 到 `document.body`，并用 depth 管理 z-index。
- `Header` 的 Vue `#control` 对应 `control` ReactNode。

文档：[Ark UI Floating Panel (React)](https://ark-ui.com/react/docs/components/floating-panel)

### FloatingPanel.Header

`children` 为标题；`control` 为右侧控制区（对应 Vue `#control`）。

### FloatingPanel.PinTrigger / OpacityTrigger

默认 Pin 图标；自定义内容放 `children`。需要读写 `pinned` / `opacity` 时用 `useFloatingPanelAppearance()`。

## Theme Configuration

根 **`tvFloatingPanel`**。`size`：`xs | sm | base | lg`；`skin`：`default | razer | shadcn`；`surface`：`light | dark | system`。

---

## 最佳实践

- 保持 Trigger + Content + Header 结构。
- 固定面板后不要再指望拖拽。
- `resizeAxis="custom"` 时自行组合 Ark `ResizeTrigger`。
- 透明度控件放在 Header `control` 里，用 appearance hook，不要 render prop。
