# Dialog

Dialog 用于确认、表单、详情等临时层。React 入口是复合组件：`Dialog`、`Dialog.Trigger`、`Dialog.Content`、`Dialog.Header` / `Body` / `Footer`、`Dialog.CloseTrigger`。基于 Ark Dialog **`Root`**（不是 `RootProvider`）。根扩展 `theme` / `craft` / `beforeClose`；关闭来源在 `onOpenChange.details.from`。

`dialog()` 可命令式唤起。应用内有 `RUIConfig` 时会挂到运行时出口，从而继承 theme / depth。组件内推荐 `useDialog()`。

```ts
const { dialog } = useDialog()
dialog.open({ title: '…', content: '…' })
```

## ARK UI Link

- 根透传 Ark `DialogRootBaseProps`（`open` / `onOpenChange` 等），并增加 `theme` / `craft` / `beforeClose`。
- `Trigger` / `CloseTrigger` 增加 `from`。
- `Content` / `Header` / `Body` / `Footer` 是 Raxium 结构层（Portal、depth、默认关闭钮与 Footer widget）。
- 状态用 `useDialogContext()`。

文档：[Ark UI Dialog (React)](https://ark-ui.com/react/docs/components/dialog)

### Dialog.Content

`ui`（backdrop / positioner / content / close）、`showClose`、`close`（替换默认关闭钮，对应 Vue `#close`）。无 Header 且 `showClose` 时显示默认 X。

### Dialog.Footer

无 `children` 时渲染 Cancel / OK。`widget.cancel` / `widget.ok` 透传 Button props（另有 `text`）。`onOk` / `onCancel`。

### Dialog.Trigger / CloseTrigger

`from` 写入本次开关来源（`TriggerFrom` 或自定义字符串）。

## Theme Configuration

根 **`tvDialog`**。`size`：`xs | sm | base | lg`；`skin`：`default | razer | shadcn`；`surface`：`light | dark | system`；`bordered` / `unstyled`。

---

## 最佳实践

- 保持 Trigger + Content + Header/Body/Footer 结构。
- 关闭来源用 `from`，不要在业务里猜测是 Esc 还是按钮。
- 异步校验放进 `beforeClose`，不要先关再开。
- 函数式弹窗在 `RUIConfig` 子树内调用，以便继承主题与 depth。
