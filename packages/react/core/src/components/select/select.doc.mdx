# Select

`Select` 用于单选或多选下拉。React 入口是复合组件：`Select`、`Select.Trigger`、`Select.Value`、`Select.Content`、`Select.Item`、`Select.ItemGroup`。基于 Ark UI Select 的 **`Root`**（不是 `RootProvider`）。根上扩展 `theme` / `craft` / `className`；浮层 `Content` 走 portal/depth + `useThemeAttrs`（与 HoverCard 同模式）。`RUIConfig.select` 提供默认 `lazyMount` / `unmountOnExit` / `placement` / `theme`。

选项集合用 `createListCollection`（从 `@raxium/react` 的 Select 模块再导出）。受控：`value` / `onValueChange`，`open` / `onOpenChange`。

Ark Select 没有 Arrow 原语，因此未封装 `Select.Arrow`。

### Select.Trigger

`clearable` 显示清空按钮；`clearIcon` / `indicator` 为 `ReactNode`（不要做成 slot / render-prop）。

### Select.Value

默认渲染 Ark `ValueText`；可用 `placeholder`。`children` 可替换展示。

### Select.Content

浮层：Positioner + Content + inner。`ui.positioner` / `ui.root` / `ui.inner`。传送后挂 `useThemeAttrs` 与 depth z-index。

### Select.Item / ItemGroup

`Item` 的 `item` 对应集合项；`indicator` 可替换默认 Check。`ItemGroup.label` 为分组标题。

## 最佳实践

- 用 `createListCollection` + `map` 渲染 Item，不要 faker。
- 受控：`value` + `onValueChange`；打开：`open` + `onOpenChange`。
- 清空用 `Select.Trigger clearable`，不要 Vue named slot。
- 样式：`theme.size` → `className` / `ui` → 根 `craft`。
