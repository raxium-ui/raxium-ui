# Tabs

`Tabs` 在同一上下文中切换多个内容面板。React 入口是复合组件：`Tabs`、`Tabs.List`、`Tabs.Trigger`、`Tabs.Content`、`Tabs.Indicator`。基于 Ark UI Tabs 的 **`Root`**（不是 `RootProvider`）。根上扩展 `theme` / `craft` / `className`。选中索引通过 root ref + `useLayoutEffect` + MutationObserver 观察 DOM（不是 Vue `watch`）。

## ARK UI Link

透传边界以 `props.ts` 中接口继承为准：

- 根继承 Ark `Root`（`value` / `defaultValue`、`orientation`、`onValueChange`、懒加载等），并增加 `theme`、`craft`、`className`。
- `Tabs.List` / `Trigger` / `Indicator` / `Content` 对应 Ark List、Trigger、Indicator、Content。

Ark UI 文档：[Ark UI Tabs (React)](https://ark-ui.com/react/docs/components/tabs)

### Tabs.List / Trigger / Indicator / Content

子件均为 **`ThemeNoCrafts`**，用 `className` 覆盖样式。`Trigger` / `Content` 需要成对的 `value`。`Indicator` 可选。

## UI Configuration

`Tabs` 组件族不提供 `ui`。用各节点 `className` 覆盖。

---

## 最佳实践

- **结构**：`Tabs > List(Trigger+Indicator) + Content`；Trigger 与 Content 使用同一套 `value`。
- **受控**：`value` + `onValueChange`；不要同时传 `value` 与 `defaultValue`。
- 标签很多时给 `Tabs.List` 限制宽度，列表会把当前项滚入视野。
- 指示器可选；不要做成 Vue slot / render-prop。
- 样式：节奏用根 `theme.size`；局部用 `className`；改 `tv*` 再用根 `craft`。
