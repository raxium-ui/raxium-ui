# TagsInput

`TagsInput` 用于管理字符串标签集合。React 入口是复合组件：`TagsInput`、`TagsInput.Item`、`TagsInput.ItemDeleteTrigger`。基于 Ark UI Tags Input 的 **`Root`**（不是 `RootProvider`）。行内模式组合 `ScrollArea` 做横向滚动。受控：`value` / `onValueChange`。

## ARK UI Link

- `TagsInput` 透传 `TagsInputRootBaseProps` 到 Ark `Root`，并扩展 `theme`、`inline`、`prefix` / `suffix` 和 `ui`。
- `TagsInput.Item` 组合 `ItemPreview`、`ItemText`、`ItemInput`。
- 删除触发器使用 `TagsInput.ItemDeleteTrigger`（Ark `ItemDeleteTrigger`）。
- 需要机器 API 时用 `useTagsInputContext()`，不要拆 `RootProvider`。

文档：[Ark UI Tags Input (React)](https://ark-ui.com/react/docs/components/tags-input)

## Theme Configuration

根 `theme` 为 `ThemeProps`。单实例优先 `ui.*` / `className`；根 `craft` 仅改 **`tvTagsInput`**。内嵌 **`tvInput`** 走应用级 preset。

`size`：`'xs' | 'sm' | 'base' | 'lg'`。`skin`：`'razer' | 'shadcn'`。`surface`：`'light' | 'dark'`。
