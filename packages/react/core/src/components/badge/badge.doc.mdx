# Badge

`Badge` 是轻量级状态标识，适合标签、计数与角标。基于 Ark UI Factory（`ark.div` / `ark.sup`），支持 `default` / `secondary` / `dot`，以及 `theme` / `craft` / `className`。`as` 在 `div` 与 `sup` 之间切换。

## ARK UI Link

`Badge` 不是 Ark 的独立组件，而是 Factory 原语封装。会消费 `variant`、`theme`、`craft`、`as`，其余 HTML 属性透传到 `div` / `sup`。

- 文档：[Ark UI React Factory](https://ark-ui.com/docs/guides/composition)
- 透传：`id`、`data-*`、`aria-*`、原生事件等；没有 Ark「Badge API」。

## UI Configuration

`Badge` 没有 `ui`。单一根节点，用 `className` / `theme` / `craft`。

---

## 最佳实践

- 纯文本或数字用 `default` / `secondary`，不要在 Badge 里放按钮等交互。
- 角标用 `variant="dot"` + `as="sup"`，并保证旁边有可读文本或 `aria-*`。
- 节奏放进 `theme.size`；局部 class 优先；改 `tvBadge` 结构再用 `craft` 或应用 `RUIConfig preset`。
