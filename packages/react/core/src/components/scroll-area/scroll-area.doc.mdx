# ScrollArea

`ScrollArea` 在固定容器内承载可滚动内容，支持垂直/水平滚动条与角落补位。React 入口是复合组件：`ScrollArea`、`ScrollArea.Viewport`、`ScrollArea.Scrollbar`、`ScrollArea.Corner`。基于 Ark UI Scroll Area 的 **`Root`**（不是 `RootProvider`）。根上扩展 `theme` / `craft` / `className` / `ui`。

滚动条是否显示由 `Viewport` 对视口与内容尺寸的测量决定，不扫描子组件类型名。

## ARK UI Link

透传边界以 `props.ts` 中接口继承为准：

- 根继承 Ark `Root` 能力，并增加 `theme`、`craft`、`className`、`ui.root`。
- `ScrollArea.Viewport` 封装 Ark `Viewport` + `Content`；滚动事件挂在 Viewport 上。
- `ScrollArea.Scrollbar` / `ScrollArea.Corner` 对应 Ark 的 Scrollbar（含 Thumb）与 Corner。

Ark UI 文档：[Ark UI Scroll Area (React)](https://ark-ui.com/react/docs/components/scroll-area)

## 最佳实践

- **结构**：`ScrollArea > Viewport + Scrollbar (+ Corner)`；内容放进 `Viewport`，不要按子组件 displayName 拆布局。
- **单轴**：只放一条 `Scrollbar`；双轴再加 `orientation="horizontal"` 与 `Corner`。
- **滚动事件**：绑在 `ScrollArea.Viewport` 的 `onScrollStart` / `onScroll` / `onScrollEnd`。
- **样式**：节奏用根 `theme.size`；局部用 `ui` / `className`；改 `tv*` 结构再用根 `craft` 或应用 `RUIConfig preset`。
- 限制容器尺寸，把滚动交给 Viewport，不要用页面滚动替代局部滚动区。
